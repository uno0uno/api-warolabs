================================================================================
                         WARO PUBLIC API DOCUMENTATION
================================================================================

Version: 2.0
Base URL: https://api.warocol.com/v1

================================================================================
                              AUTHENTICATION
================================================================================

All endpoints require authentication via API token. You can authenticate using
one of the following methods:

1. Bearer Token (Recommended)
   Header: Authorization: Bearer waro_sk_xxxxxxxxxxxxx

2. API Key Header
   Header: X-API-Key: waro_sk_xxxxxxxxxxxxx

API tokens are generated from the Waro dashboard under Settings > API Keys.

================================================================================
                              SCOPES
================================================================================

API tokens have specific scopes that determine access:

- orders:read  - Access to sales/orders endpoints
- menu:read    - Access to menu endpoints (products, recipes, modifiers)
- read         - Full read access to all endpoints

1. GET SALES LIST
--------------------------------------------------------------------------------
POST /v1/sales

Retrieves a paginated list of sales/orders for the authenticated tenant.

Request Body:
{
    "limit": 50,              // Number of results (1-250), default: 50
    "offset": 0,              // Number of results to skip, default: 0
    "paymentMethod": null,    // Filter: "cash", "card", "digital"
    "status": null,           // Filter: "completed", "cancelled", "pending"
    "sortField": "order_date",// Sort field, default: "order_date"
    "sortDirection": "desc",  // Direction: "asc" or "desc", default: "desc"
    "dateFrom": null,         // Start date filter (YYYY-MM-DD)
    "dateTo": null,           // End date filter (YYYY-MM-DD)
    "timezone": "America/Bogota" // IANA timezone for date filters
}

Response:
{
    "success": true,
    "data": [...],            // Array of sale objects
    "pagination": {
        "total": 100,
        "limit": 50,
        "offset": 0,
        "hasMore": true
    }
}

Required Scope: orders:read or read

2. GET SALES METRICS (Consolidated Analytics Endpoint)
--------------------------------------------------------------------------------
POST /v1/sales/metrics

Retrieves sales metrics with optional grouping for analytics.

Request Body:
{
    "dateFrom": null,         // Start date filter (YYYY-MM-DD)
    "dateTo": null,           // End date filter (YYYY-MM-DD)
    "timezone": "America/Bogota", // IANA timezone for date filters
    "groupBy": null,          // Grouping: null, "weekday", "hour", "product", "payment", "ticket"
    "limit": 20,              // For "product" grouping: number of results (1-100)
    "sortBy": "quantity",     // For "product" grouping: "quantity" or "revenue"
    "ranges": null            // For "ticket" grouping: custom price ranges
}

GROUPBY OPTIONS:

null (default) - Overall metrics:
{
    "success": true,
    "data": {
        "totalSales": 12413500,
        "totalOrders": 532,
        "completedOrders": 532,
        "cancelledOrders": 0,
        "pendingOrders": 0,
        "avgTicket": 23333.64
    }
}

"date" - Metrics grouped day by day:
{
    "success": true,
    "data": [
        {
            "date": "2026-01-15",
            "dayName": "Thursday",
            "totalOrders": 28,
            "totalSales": 654000.0,
            "avgTicket": 23357.14
        }
    ]
}

"weekday" - Metrics grouped by day of week:
{
    "success": true,
    "data": [
        {
            "dayNumber": 0,             // 0=Sunday, 6=Saturday
            "dayName": "Sunday",
            "dayCount": 4,              // distinct Sundays in the period
            "totalOrders": 49,
            "totalSales": 916000.0,
            "avgTicket": 18693.87,
            "avgOrdersPerDay": 12.3,    // average orders per Sunday
            "avgSalesPerDay": 229000.0  // average revenue per Sunday
        }
    ]
}

"hour" - Metrics grouped by hour of day:
{
    "success": true,
    "data": [
        {
            "hour": 19,
            "hourLabel": "19:00",
            "dayCount": 30,             // distinct days with activity at this hour
            "totalOrders": 98,
            "totalSales": 2356500.0,
            "avgTicket": 24045.91,
            "avgOrdersPerDay": 3.3,     // average orders per day at this hour
            "avgSalesPerDay": 78550.0   // average revenue per day at this hour
        }
    ]
}

"product" - Top selling products (use limit and sortBy):
{
    "success": true,
    "data": [
        {
            "rank": 1,
            "productId": "uuid",
            "productName": "COMBO 1 HAMBURGUESA RES",
            "categoryName": "Combos",
            "totalQuantity": 141,
            "totalRevenue": 2150500.0,
            "ordersCount": 119,
            "avgPrice": 15252.0
        }
    ]
}

"payment" - Sales breakdown by payment method:
{
    "success": true,
    "data": [
        {
            "paymentMethod": "cash",
            "ordersCount": 308,
            "ordersPercentage": 57.9,
            "totalSales": 6942500.0,
            "salesPercentage": 55.9,
            "avgTicket": 22540.58
        }
    ]
}

"ticket" - Distribution by ticket price ranges:
{
    "success": true,
    "data": [
        {
            "range": "$0 - $15,000",
            "ordersCount": 185,
            "percentage": 34.8,
            "totalSales": 1993500.0,
            "avgTicket": 10775.67
        }
    ]
}

Default ticket ranges: [0, 15000, 25000, 40000, 60000, 100000]
Custom ranges example: {"ranges": [0, 10000, 20000, 50000]}

Required Scope: orders:read or read

3. GET SALE DETAIL
--------------------------------------------------------------------------------
POST /v1/sales/detail

Retrieves detailed information about a specific sale including all items
and modifiers.

Request Body:
{
    "orderId": "uuid-string"  // Required: Order UUID
}

Response:
{
    "success": true,
    "data": {
        "id": "...",
        "orderNumber": 10054,
        "orderDate": "...",
        "items": [...],       // Array of order items with modifiers
        "totals": {...}
    }
}

Required Scope: orders:read or read

4. GET MENU PRODUCTS
--------------------------------------------------------------------------------
POST /v1/menu/products

Retrieves the list of menu products with their ingredients, recipe bases,
and modifier groups.

Request Body:
{
    "limit": 50,              // Number of results (1-250), default: 50
    "offset": 0,              // Number of results to skip, default: 0
    "categoryId": null,       // Filter by category UUID
    "isAvailable": null,      // Filter by availability (true/false)
    "includeIngredients": true,   // Include direct product ingredients
    "includeRecipeBases": true,   // Include associated recipe bases
    "includeModifiers": true      // Include associated modifier groups
}

Response:
{
    "success": true,
    "data": [
        {
            "id": "...",
            "name": "Product Name",
            "price": 15000,
            "categoryId": "...",
            "categoryName": "Category",
            "isAvailable": true,
            "ingredients": [...],     // Direct ingredients with quantities
            "recipeBases": [...],     // Recipe bases with their ingredients
            "modifierGroups": [...]   // Modifier groups with options
        }
    ],
    "pagination": {
        "total": 50,
        "limit": 50,
        "offset": 0,
        "hasMore": false
    }
}

Required Scope: menu:read or read

================================================================================
                              TIMEZONE SUPPORT
================================================================================

All date-based queries support IANA timezone identifiers. This allows you to
filter data according to your local timezone.

Common timezone examples:
- America/Bogota      (Colombia)
- America/Mexico_City (Mexico)
- America/New_York    (US Eastern)
- America/Los_Angeles (US Pacific)
- Europe/Madrid       (Spain)
- Europe/London       (UK)

If not specified, the default timezone is America/Bogota.

================================================================================
                              ERROR RESPONSES
================================================================================

All errors follow this format:

{
    "success": false,
    "error": {
        "code": "ERROR_CODE",
        "message": "Human readable error message"
    }
}

Common error codes:
- UNAUTHORIZED        - Invalid or missing API token
- FORBIDDEN          - Token lacks required scope
- NOT_FOUND          - Resource not found
- VALIDATION_ERROR   - Invalid request parameters
- INTERNAL_ERROR     - Server error

================================================================================
                              RATE LIMITING
================================================================================

API requests are rate limited per API token:
- 100 requests per minute
- 1000 requests per hour

Rate limit headers are included in all responses:
- X-RateLimit-Limit
- X-RateLimit-Remaining
- X-RateLimit-Reset
